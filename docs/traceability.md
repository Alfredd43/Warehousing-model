# Business rules, SQL and checks: traceability

Each rule from the [Spec](../00_req_feedback/Assignment2_Spec.md) and the [architecture design](Architecture_and_Data_Model.md) is mapped to the SQL that implements it and the checks that verify it. File paths are relative to `workspace/`. Check names in `tests/check_demo.py` start with the rule id, so `grep R14 tests/check_demo.py` finds every check for rule R14.
